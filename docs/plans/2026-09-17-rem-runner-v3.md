# REM Runner V3 Plan

**Goal:** Turn the V2 mechanical prototype into a production-ready vertical slice with original art, audio, saves, and a polished reward loop.

## V3 scope

1. Replace vector placeholders with original sprite sheets for the REM runner, five enemies, the boss, ink impacts, workshop machines, and portal.
2. Add animation state transitions: idle, walk, run, crouch, jump, fall, aim, fire, repair, hurt, and victory.
3. Add Web Audio placeholder synthesis first, then replace it with original machine, ink, portal, and reward sounds.
4. Add local progression: finished levels, best grades, unlocked apparel placeholders, and selected ink loadout.
5. Add workshop panels for worlds, cosmetics, records, and optional REM store reward links. Store links remain outside levels.
6. Add finish-screen score submission, monthly leaderboard confirmation, and coupon rewards only after a completed world.
7. Profile on mobile and add accessibility settings: reduced motion, sound mute, contrast, and touch target tests.

## Definition of done

- All V2 mechanics retain 60fps target behavior on a 390px mobile viewport.
- Every player state has an original visual animation.
- Progress and best grade survive reload.
- Completed-world reward submits exactly one score and can show a coupon.
- No Nintendo assets, audio, names, levels, or visual motifs are used.
